### 가장 중요한 발견 3가지

1. **아이콘 구현 방식이 근본적으로 다름(V2-045, 050)** — v1/실제 코드는 SVG 벡터 아이콘 체계(`Icon.jsx`)인데, 이 v2 컨셉은 **SVG를 단 하나도 쓰지 않고 유니코드 텍스트 문자로 아이콘을 흉내냄**. 디자인 목업 단계라서 그런 것인지, 실제 구현 방향을 바꾸려는 의도인지 확인이 필요함.
2. **뒤로가기 버튼의 접근성·원칙 위반(V2-052, 056)** — 텍스트도 `aria-label`도 없는 아이콘 단독 버튼으로, v1의 "화살표·아이콘 단독 버튼 금지" 원칙에 정면으로 위반됨. 실제 앱의 `AppHeader.jsx`는 이미 `aria-label`을 갖추고 있어, 이 v2 컨셉이 오히려 기존 코드보다 접근성이 후퇴한 형태임.
3. **버튼·헤더 모두 "일관성" 원칙에서 벗어남(V2-060, 051)** — 한 화면 안에 radius가 8px/12px/100px로 제각각인 버튼 3종이 공존하고, 헤더도 3존 구조 대신 1존만 남아 v1이 강조한 "같은 역할은 항상 같은 모습" 원칙과 거리가 있음. 새로운 디자인 방향으로 의도된 것인지 팀 확인이 필요함.

입력 필드 쪽에서는 **4가지 상태(기본/Focus/Error/Disabled) 중 "기본"만 존재**하는 것이 가장 큰 공백(V2-064)이며, "국적" 드롭다운이 실제 동작하지 않는 정적 장식 요소인 점(V2-065)도 구현 단계에서 반드시 실제 컴포넌트로 교체해야 할 부분으로 남겨둠.
